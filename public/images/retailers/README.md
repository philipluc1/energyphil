# Retailer logos

Drop a retailer's logo here with the exact file name below and it shows on
the results, the dashboard and the "Get this plan" box. Until a file exists,
the site shows a coloured badge with the retailer's initials.

SVG is best; PNG works (square-ish, at least 200 x 200, transparent background).
Only use logo files you have permission to use (most retailers have a media
or brand page, or will send them on request).
